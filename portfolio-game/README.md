# ML Journey - Interactive Portfolio Game

A modern, interactive portfolio website that presents Nandan Hemanth's career journey as an engaging game-like experience.

## 🎮 Features

### Interactive Gaming Experience
- **Journey Map**: Navigate through career milestones as game levels
- **Progressive Unlocking**: Levels unlock automatically as you explore
- **Dynamic Animations**: Smooth transitions and engaging visual effects
- **Immersive UI**: Futuristic, AI-themed design with neural network backgrounds

### Fixed Navigation Bar
- **Resume Download**: Direct download of Nandan's resume
- **GitHub Access**: Quick link to GitHub profile
- **LinkedIn Connection**: Easy access to LinkedIn profile
- **Always Accessible**: Pinned navigation available from anywhere

### Career Journey Levels
1. **The Beginning** - Bachelor's at PES University
2. **First Deep Dive** - DRDO Internship (WANI TTS System)
3. **Capstone Achievement** - Blabber Call Translator
4. **Full-Stack Evolution** - Boltcode Development
5. **AI Pipeline Mastery** - Channel-AI Internship
6. **Graduate Level Up** - Stevens Institute (Current)
7. **Hackathon Champion** - MacroMind & Flexa Victories
8. **Research Frontier** - Master's Thesis (In Progress)

### Interactive Level Details
- **Comprehensive Information**: Detailed descriptions, highlights, and achievements
- **Technology Tags**: Technologies and skills used in each milestone
- **External Links**: Direct access to projects and publications
- **Animated Highlights**: Dynamic cycling through key achievements

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation & Running
```bash
# Install dependencies
npm install

# Start development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Build for Production
```bash
npm run build
```
